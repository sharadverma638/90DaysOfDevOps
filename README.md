## 🎯 Why This Challenge

Watching tutorials is easy. Running production-like systems, breaking them, and fixing them is where the real learning happens.

This challenge is my attempt to move from *knowing about* DevOps to *being able to do* DevOps - through:

- Strong fundamentals, built from first principles
- Hands-on practice with the actual tools, not just slides
- Real troubleshooting, not scripted demos
- Small projects that connect concepts together
- Consistent, visible progress - tracked and documented

**My working principle:** *Learn → Practice → Troubleshoot → Build → Document → Repeat.*

---

## 📚 How I'm Approaching It

Rather than rushing through a strict day-by-day schedule, I'm working through the challenge **group by group**. Each group gets the time it needs before I move to the next - because the goal is depth, not just a completed checklist.
